# Internal function - Determine if "invalid multibyte string" error will be triggered due to wrong encoding.

Internal function - Determine if "invalid multibyte string" error will
be triggered due to wrong encoding.

## Usage

``` r
has.invalid.multibyte.string(x, return.elements = FALSE)
```

## Arguments

- x:

  String vector to be tested

- return.elements:

  Logical value. If \`TRUE\`, then the function returns a logical value
  for each element of x, otherwise a single logical is returned for the
  entire vector.
